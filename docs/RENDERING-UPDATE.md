# 住宅主体与渲染品质修订

## 本轮实现

1. 独立住宅模型模块：三种体块轮廓，保留现有地块及碰撞矩形，入口旋转朝向最近道路。主体包含基座、实体墙、石材窗台、玻璃与框架、错层上翼、开敞露台、遮阳格栅和家具；住宅移除商业横幅。
2. 独立树冠几何模块：小型暗色内芯、分布在外围的折面叶片、叶片颜色层次和柔化法线；多株树共享三套几何与实例颜色，提供两档远景几何。
3. 统一日照配置：方向光、天空、环境反射和海湖水面共享太阳方向。降低暖色直射与填充光的色偏；缩小近景阴影覆盖范围以提高细节，使用光源空间的纹素对齐代替每两米移动阴影中心。
4. 接触暗部：建筑基座与树根的静态柔和贴花，按物理高度场细分贴地，分区合批；标准/低画质分别使用 950/420 米距离限制。
5. 材质：使用原有贴图和已有颜色采样生成小幅度导数凹凸，不新增渲染通道。地表混入两种尺度的草地纹理，调整草、土与沙色彩关系。仍沿用原生抗锯齿、ACES 色调映射与 sRGB 输出。
6. 道路与海岸：加入路缘的竖直侧面、W 形截面护栏与反光块；修正海面浅滩/泡沫计算，使用和地图相同的岸线扰动，加入视角相关的海面反射色。

## 必要检查

仅执行一次 npm run build，成功：55 模块，主 JS 709.95 kB（gzip 196.12 kB），仍有超过既有 650 kB 分块阈值的提示。

没有运行浏览器、GPU 着色器编译、场景装配、截图、自动驾驶、比赛回归或性能测试。本轮计数仅为构建产物数据，不是帧率、视觉或玩法的验证结论。代码检查时确认法线细节插入 Three.js 材质的法线计算阶段，但这不能替代实际 GPU 运行。

## 已知局限

- 本轮是主体模型、材质与渲染的实质修改，不代表已达到商业成品美术水准；需要实际驾驶画面来确认最终效果。
- 住宅窗户使用外观几何与不透明反射玻璃，没有室内。道路路缘为视觉几何，未增加独立的轮胎上路缘物理响应。
- 树叶是程序生成的风格化几何，没有动态风场；模型切换沿用既有距离 LOD，没有渐变过渡。
- 接触暗部为静态近似；海面反射色与环境贴图不提供场景实时镜面反射。地形、主车和其他所有景物没有全部重建。
- 更细树冠及接触暗部增加的 GPU 开销未实测，低画质通过既有分辨率、几何和可视范围控制开销。

## 运行

双击根目录“启动游戏.cmd”，或运行 npm start；生产静态资源位于 dist。无需新增依赖或素材。本轮没有启动临时服务器、没有自动推送 GitHub 或部署。
