# 道路外社区景观

新增模块 src/scenery/open-spaces.js，在道路外围约 36–82 米的空地布置用途明确的片区。场地使用已有地形、道路及障碍数据判断，不移除现有建筑树木。后续地被生成避让新片区。

- 5 座网球场：双打/单打和发球区标线、球网、侧后围网、金属立柱、球员长椅。围网纹理由 Canvas 在本地生成。
- 9 片柑橘园：成行分枝果树、果实、果筐、中央步道及休息棚架。
- 9 处社区花圃：抬高种植箱、混合花蔬、攀爬架和园艺工作棚。
- 7 处雕塑花园：双环雕塑、步道、草坪、棚架桌椅与低矮绿篱。

模型复用既有几何、材质和空间实例化，沿用低画质和可视距离管理。没有下载资源或新增依赖。地点名称和颜色接入自由驾驶迷你地图及途经提示，不修改比赛路线。

必要检查：一次 CPU 场景装配确认四类共 30 处成功生成，场景批次未发现缺失几何；一次生产构建。未运行浏览器、截图、驾驶、比赛或帧率测试，不将生成数量当作画面与性能验证。球场和园艺设施暂为景观，地块设有碰撞边界，没有体育/采摘互动；入口标识也不代表汽车可进入整个地块。

本地通过根目录“启动游戏.cmd”或 npm start 游玩。dist 为本地生产版本，按现有 .gitignore 不提交 Git；仓库既有 CI 会在 push 后运行自己的测试与构建并上传 dist artifact。本轮不修改该工作流，也不自动部署服务器。
