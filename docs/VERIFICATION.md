# 本轮交付记录（2026-09-06）

本轮目标：把地图升级后遗留的红色测试恢复绿色，将画面推进到"地中海海岛公路旅行"的美术方向，并把核心路线的节奏地标补齐。

## 已实现

- 表面材质：柏油（漫反射+粗糙度）、岩壁、灰泥墙面、草地、沙滩接入世界投影材质管线（Poly Haven CC0，随项目分发），并按表面控制纹理混合强度。
- 光照与天空：暖阳、柔化阴影、指数雾与 exposure 调整、程序化云层；低岸边坡真实没入海面形成沙滩，海崖保持陡峭。
- 植被与岩石：松树改为层叠锥体、橄榄树改为不规则树冠、棕榈叶片加密下垂、岩石改为多面体碎石轮廓；护栏接缝消除。
- 路线节奏：新增港口路连通老城与帆船码头（第五处风景移至码头，更名"老城码头"）；松岭之巅发卡弯前增设观景台；老城入口立"棕榈港"拱门。
- 玩法：三场比赛新增金/银/铜牌目标（标准杆取自路线驾驶器实测 ×1.08 / 1.3 / 1.6），奖牌与个人最佳一起存入 Local Storage。
- 工程：QA 面板挂载于 `?qa=1`；新增 GitHub Actions（npm ci → test → build）；修复上一版遗留的失败测试与五个已知小 bug（音效开关、欢迎按钮文案、检查点 HUD、bodyRoll、Race.splits）。

## 验证记录

- `npm test`：9 项全部通过（含环岛 36 检查点完整脚本驾驶、路网连通、碰撞防穿透）。
- 三场比赛均由 RoutePilot 以正常转向/油门输入完整跑完，0 救援 0 碰撞：晴湾冲刺 62.3s、松岭爬山 97.7s、环岛长赛 193.3s。
- 生产构建 `npm run build` 成功（主包 gzip 约 163 kB，QA 面板独立分包，仅 `?qa=1` 加载）。
- 浏览器冒烟：页面加载无 fatal、欢迎页/自由驾驶/三个新地标（拱门、观景台、码头）逐一实机查看并截图存档于 `docs/screenshots/`。

## 限制

- 帧率验证在内嵌浏览器的软件渲染下进行（1600×900 约 50 FPS），仅证明无渲染错误，不代表真机 GPU 性能；标准 60 FPS 目标依赖真机确认。
- 车辆仍为程序化模型，未替换外部 glb；音效仍为程序合成。
- 未做：多分辨率矩阵、长时耐久、真机手柄、移动端适配。
