# 海风疾驰 / COASTLINE

## 最新：道路外的社区景观

别墅后方及公路外侧新增 30 处完整片区：5 座网球场、9 片柑橘园、9 处社区花圃、7 处雕塑花园。包含球场标线与围网、柑橘树与果筐、种植箱与园艺棚、青铜色环形雕塑与遮阳休憩区。选址约在道路外侧 36–82 米处，避让湖区、道路和既有设施；新地块之间也保持间距，草地小景避开新片区。迷你地图显示相应标点，靠近后显示地点名称。

这些是驾驶场景中的景观设施，尚未提供网球、采摘或园艺小游戏；地块主体有碰撞边界。没有新增依赖和下载资源。本轮仅做一次 CPU 场景生成检查与一次生产构建，不做浏览器或比赛回归。

## 此前：住宅主体与渲染品质修订

住宅主体改为三种不同轮廓：错层翼楼、带开敞露台的住宅和低层院墅；入口朝向附近道路，补充窗洞边框、窗台、侧窗、门把手、遮阳构件及屋顶家具。此前庭院和公共设施继续保留。石松、橄榄树的实心球状树冠改为有空隙的折面叶簇，并配置两档远景几何。

统一太阳、天空、环境反射与海湖高光；移动阴影改用光源空间的纹素对齐。新增贴地的建筑/树根柔和接触暗部，使用空间分块控制绘制距离。道路增加路缘侧面和 W 形截面金属护栏；地表、灰泥、木材和铺装复用既有贴图生成微表面法线细节。海面浅滩色带与泡沫现在跟随实际岸线起伏。

本轮只做一次生产构建，成功生成 dist。没有浏览器、截图、GLSL 实机编译、驾驶或帧率测试；这不代表最终观感已获验证。没有下载素材、安装依赖、推送或部署。详细说明见 docs/RENDERING-UPDATE.md。

## 此前：别墅庭院与连续街景

住宅调整为两层为主的体量和实体窗墙；在住宅前侧、侧边的合适空地附建入口车道、门柱、信箱、收起的格栅门、种植池，以及泳池露台、遮阳客厅或带烧烤台和水槽的户外庭院。家具增加软垫、靠枕、细金属框架，花盆采用旋转曲面，盆栽使用弯曲叶片；泳池增加压顶、扶梯与动态水纹。入口铺装贴合驾驶地面。

公共空间增加沿海铺装步道、花摊、自行车架、遮阳休息区、花箱路灯和商业前场。庭院优先与房屋关联，其余设施再填充道路边的空隙；采用矩形占地避让道路、湖泊、建筑和既有障碍，草丛也避开新铺装。共享几何、材质与区域实例化沿用现有画质管理。

这一轮只做一次 CPU 场景装配检查和一次生产构建。没有新增浏览器画面、驾驶或帧率验证；下方旧截图与历史检查记录不代表本轮效果。新设施属于景观，尚无人物、购物、烧烤或泳池互动，车辆与全地图也未全面重建。

一款面向电脑浏览器的单人 3D 海岛驾驶试玩版。使用 Three.js + Vite；车辆、地图、建筑与音效由项目代码生成，地表材质采用随项目分发的 Poly Haven CC0 贴图。运行时无需访问 CDN、素材站或外部 API。

当前版本采用现代海滨度假城方向：暖白退台建筑、落地玻璃店面、木格栅与露台；跑车改为蓝绿色金属车漆、平滑曲面车身、轮拱开口、细灯带与一体式鸭尾。棕榈采用连续弯曲树干，石松与橄榄树采用分枝和不规则树冠；灯塔、城市入口与山顶展馆统一为简洁的现代轮廓。新模型继续使用实例化、空间裁剪和远景简化。港湾、沙滩、谷地和海崖既有布局保留。

景观修订已通过本地 Chrome 的实际驾驶视角做前后对比：地表采用草、土、石与沙分层材质，海岸增加成片草丛和灌木，室外环境反射替换室内反射。图片见 docs/screenshots/landscape-after.jpg。只做启动与画面确认，未跑完整比赛、自动驾驶或帧率测试；地图整体轮廓和建筑组合仍需要进一步美术制作。详细记录见 docs/VERIFICATION.md。

## 无限氮气与镜湖公园

按 Esc，在暂停菜单开启「无限氮气」；开关会保存到当前浏览器。继续驾驶后，按住油门和 Shift 使用氮气，能量条显示「∞ 无限」。关闭后恢复正常消耗与补充。比赛途中只要开启过无限氮气，该次结算不写入普通最佳成绩或奖牌记录，原纪录保留。

城市中央新增镜湖公园：独立淡水湖、真实湖盆、喷泉、木栈道、观景亭、树丛、芦苇与睡莲。迷你地图中央的蓝色湖面旁有一圈环湖慢行道，从东侧城市街道通过「镜湖入口」可驾车进入。新增一个公园发现点；驶入湖水会复位到安全道路。道路边的合适空地增加休憩庭院、花箱、廊架、自行车和小型水景。

本次仅进行无限氮气与湖路边界/复位的核心逻辑检查，生产构建一次成功，未运行浏览器或新增截图。喷泉低画质减少水滴，并在远处停止绘制。

## 直接游玩

本次交付已包含生产构建 `dist/`。在当前 Windows 电脑上，双击 **`启动游戏.cmd`**，默认浏览器将打开 `http://127.0.0.1:8765`。

- 保持启动窗口打开，游玩结束后在窗口按 **Ctrl+C**，或关闭该窗口。
- 也可在项目目录运行 `npm start`，再打开终端显示的网址。
- 端口占用时，可运行 `node scripts/serve.mjs --port=8766`。
- 本地启动器仅使用 Node.js 标准库，有 `dist/` 时无需保留 `node_modules/`。
- 本版使用 ES Modules，请通过启动器或静态服务器访问，不能直接双击 HTML 文件运行。
- 浏览器需要支持 WebGL 2 和 Web Audio。音效在点击“出发”后启动，可在暂停菜单关闭。

## 操作

| 按键 | 功能 |
| --- | --- |
| W / ↑ | 加速 |
| S / ↓ | 刹车，低速继续按住可倒车 |
| A、D / ←、→ | 转向 |
| 空格 | 手刹漂移 |
| Shift | 氮气加速 |
| R | 自由驾驶时回到最近道路；比赛时回到上一个已通过检查点，增加 3 秒罚时 |
| Esc | 暂停 / 继续 |
| F | 切换全屏（浏览器支持时） |

弯前先松油或刹车，短按手刹甩尾，出弯再用氮气。公路之外同样可以使用氮气：草地阻力大、减速明显，沙滩松软但仍能保持高速，路肩不再误判为越野。松开手刹后抓地力逐渐恢复。氮气耗尽后需要短暂恢复，漂移时补充更快。

## 地图与比赛

- **棕榈港**：连通的城市路网，带店面、屋顶、窗框、遮阳棚和街道设施。
- **晴湾海岸**：沿海公路、棕榈步道、灯塔、沙滩和帆船码头。
- **松岭山道**：真实地形高度、起伏连续弯道、松树林与观景台。
- 新增 **橄榄谷地** 与 **北岬海崖**，从老城穿过果园和山脊，再沿海岸返回。
- 点击“选择公路挑战”进入赛事菜单：**晴湾海岸冲刺 / 松岭爬山挑战 / 晴湾环岛长赛**，分别包含 14 / 20 / 36 个检查点，路线长度在菜单显示，起跑有 3 秒倒计时。
- 亮黄色门架是当前检查点，迷你地图中的青色线是比赛路线，箭头指向下一个目标。
- 漏过检查点需要返回通过；不得跳过。可以按 R 回到上一检查点，但会罚时。
- 冲线后显示用时、个人最佳、奖牌（金/银/铜，按各赛事目标时间）、最高车速和累计罚时，可以再次挑战或继续探索。
- 个人最佳、奖牌与画质、音效设置保存在当前浏览器的 Local Storage。不同浏览器、端口或部署域名各自保存。
- 自由驾驶时，靠近地图上的五处风景点会自动发现并保存记录；左上角显示尚未发现的景点与直线距离。距离提示不是逐路口导航。
- 暂停菜单可调整音量、切换画质、选择其他比赛。旧版小岛成绩保留在浏览器中，新路线使用独立记录。

## 开发与构建

已在 Node.js 24.19.0 环境验证。Vite 8 要求兼容的现代 Node.js（详见其官方文档）。

```sh
npm ci
npm run dev
npm run build
npm run preview
```

`npm ci` 根据锁文件安装项目内依赖，首次需要网络；之后可离线运行和构建。安装命令不会安装全局依赖。若本机 npm 镜像不可用，可仅对本次命令指定官方仓库：

```sh
npm ci --registry=https://registry.npmjs.org --cache .npm-cache
```

生产构建位于 `dist/`。代码路径：

| 路径 | 内容 |
| --- | --- |
| `src/physics.js` | 120 Hz 固定步长车辆物理、检查点与比赛状态 |
| `src/world-data.js` | 道路、地形、障碍物、空间索引、碰撞 |
| `src/scenery.js` | 场景组装基类，各美术层由 island-scene 提供 |
| `src/world-layout.js` | 岛屿范围、地区名称、主环线路点与赛事定义 |
| `src/island-scene.js` | 分块地形、区域建筑、海水、植被及地标美术 |
| `src/art-materials.js` | 共享纹理与保持实际尺度的表面投影 |
| `src/vehicle.js` | 程序化跑车、轮胎、灯光与氮气火焰 |
| `src/renderer.js` | Three.js 渲染、色彩、光影和镜头遮挡 |
| `src/effects.js` | 有上限的烟雾池和环形轮胎痕迹缓冲 |
| `src/audio.js` | 本地 Web Audio 合成音效 |
| `src/main.js` | 输入、HUD、设置与完整游玩流程 |
| `tests/game.test.mjs` | 驾驶、碰撞、路网、比赛回归测试 |
| `src/qa.js`、`src/pilot.js` | 浏览器验证面板（地址加 `?qa=1` 启用）与测试驾驶器 |

## 画质与资源消耗

标准画质目标上限为 60 FPS；低画质上限为 30 FPS，并降低像素比例、阴影分辨率和烟雾数量，缩短清晰可视距离。实际帧率取决于显卡、分辨率和浏览器。

页面失焦或隐藏时自动暂停，清空按键并暂停音频。暂停时不运行物理，只低频刷新画面；隐藏页面停止游戏帧调度。车辆使用近地驾驶物理，未模拟腾空翻滚、车损和可破坏建筑。

## 部署到 GitHub / 静态服务器

没有后端、数据库、密钥或登录配置。`vite.config.js` 使用相对资源路径 `base: './'`，可部署在网站根目录或项目子路径。

1. 将源码、`package.json`、`package-lock.json`、说明与许可证上传 GitHub。忽略 `node_modules/`、`.npm-cache/`、测试临时文件。
2. 构建环境运行 `npm ci`、`npm run build`。
3. 将 **`dist/` 内部的全部内容**复制到 Nginx、Apache 或其他静态托管目录。
4. 入口为 `index.html`，浏览器直接访问该目录即可。

GitHub Pages 可使用官方 Actions 的静态站点部署流程，以 `dist/` 为发布目录；本项目没有替你创建远程仓库、提交、推送或发布。若自行配置 Nginx，可使用：

```nginx
location /coastline/ {
    alias /var/www/coastline/;
    index index.html;
    try_files $uri $uri/ =404;
}
```

把 `dist/` 内的文件放入 `/var/www/coastline/`。服务器需正确返回 JavaScript 和 CSS 的 MIME 类型。

## 验证与限制

验证记录见 `docs/VERIFICATION.md`。`npm test` 包含驾驶、碰撞、路网连通与三场比赛的脚本驾驶回归；正式入口不加载验证面板（`?qa=1` 时才挂载）。

当前版本没有 AI 交通、多人联机、手柄、手机触屏或存档同步。程序合成引擎音色与简化车辆动力学适合街机驾驶，与专业赛车模拟器有所不同。

## 清理

先关闭游戏页，并停止本项目启动窗口中的进程，然后按需删除：

- `node_modules/`：开发依赖，可用 `npm ci` 重新安装。
- `.npm-cache/`：本项目安装缓存，可直接删除。
- `dist/`：生产构建，可用 `npm run build` 重新生成。
- `docs/screenshots/`：游戏截图，删除不影响运行。
- 整个项目文件夹：彻底移除项目；未创建开机启动项或计划任务。

浏览器个人纪录不在项目文件中；需要时在该游戏站点的浏览器站点数据中清除。无需清除其他站点的数据。
