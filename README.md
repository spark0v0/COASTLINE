# 海风疾驰 · COASTLINE

一款面向电脑浏览器的单人海岛公路驾驶试玩版。驾驶 APEX S1 概念跑车，穿过住宅、花园与海岸，探索镜湖和山路，挑战三场计时赛。

![晴湾花园路的真实游戏画面](docs/screenshots/final-scenery-2026-09-10.jpg)

**当前版本：单人公开试玩版（2026-09-10）。** 分层树冠、维护草坪、砌石住宅和面向海湾的连续弯道已整合，保留概念跑车和三场比赛。完成短启动、加速、转向与暂停恢复检查；没有重新跑全地图、完整比赛或硬件性能测试。详见[交付与检查记录](docs/FINAL-RELEASE.md)。

## 开始游玩

**本次交付的本地项目已包含生产构建。** 在 Windows 双击 **启动游戏.cmd**，浏览器将打开 http://127.0.0.1:8765 。启动窗口保持打开，结束后按 Ctrl+C 或关闭窗口。

也可以在项目目录运行：

```sh
npm start
```

本地启动需要已有 Node.js。静态服务器上的游戏只需浏览器，无需安装游戏。不要直接双击 dist/index.html，浏览器会限制资源加载。

**从 GitHub 首次取得源码**，使用 Node.js 24，在项目目录执行：

```sh
npm ci
npm run build
npm start
```

依赖只安装到项目内。开发修改可运行 `npm run dev`。仓库不提交 node_modules 和 dist；本地制作交付包含 dist，现有 GitHub Actions 在成功构建后也会生成 dist 下载产物。

## 先开哪条路

点击 **出发，自由驾驶**，从约 **892 米的晴湾花园路**起点出发。跟随迷你地图的金线，穿过住宅和花园，驶向海湾、沿海弯道与观景支路。

HUD 会提示当前路线区段和距观景点的距离。住宅后方的缓坡逐渐下降，接近海岸时可看见海面与外海小岛。

随时按 Esc，选择 **自由漫游：晴湾花园路** 回到路线起点；这会退出当前比赛。点击 HUD 的 **选择公路挑战**，选择海岸、山路或环岛比赛。顺序通过全部检查点后查看成绩，可重试或继续探索。漏过检查点需要驶回目标；R 重置会影响比赛用时，比赛面板会提示规则。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 加速、刹车/倒车、转向 |
| 空格 | 手刹漂移 |
| Shift | 氮气加速，配合油门 |
| R | 回到安全道路位置 |
| Esc | 暂停、继续与设置 |
| F | 全屏 |

入弯前先松油或刹车，短按空格发起漂移，出弯再加氮气。暂停菜单可以调整标准/低画质、音量，以及无限氮气。

个人纪录、观景发现和设置保存在当前浏览器。**开启过无限氮气的比赛不写入普通最佳纪录**；旧纪录不会因此清空。更换浏览器、网址或清理站点数据，会使用另一份或清空本地存档。

## 分享与部署

运行时车辆、HDR 和地表贴图均随项目提供，不请求外部素材站。新增主车与日光资源合计约 **11 MB**；首次访问须等待加载完成。

构建后将 **dist 目录内的全部内容**发布到任意支持静态文件的网站，保留 assets、licenses 子目录。支持网站子目录部署。具体见[静态部署说明](docs/DEPLOYMENT.md)。

主车改编自 Car Concept，采用 **CC BY 4.0**；HDR 和地表素材采用 **CC0**。分享构建时必须保留车辆署名与许可证。完整记录见[资源许可](ASSET-LICENSES.md)和[游戏内署名](public/licenses/COASTLINE-CREDITS.txt)。

## 当前限制

- 远景树木仍有重复感，部分旧设施、停放车辆和外海小岛保持简化造型。树冠使用分层叶片遮罩，近看仍有片状痕迹。
- 主车使用简化的深色玻璃，未提供内饰、第一人称或损坏系统；庭院可进入部分区域，建筑室内不开放。
- 交通与居民尚未实现；景观设施以外观和探索为主。
- 低画质保留，但本轮没有测硬件帧率，也没有重新验证全地图碰撞和三场比赛。
- 暂以支持 WebGL 2 的现代电脑浏览器为目标，没有手机操作适配或跨浏览器兼容保证。

## 清理项目

先关闭本地启动窗口。删除 dist 可以清除构建，之后用 `npm run build` 重建；删除 node_modules 后需要重新 `npm ci` 才能开发构建。删除 .tmp 可以清理下载原件和临时浏览器资料，不影响游戏运行。

若想完整保留可重新制作的项目，请保留 src、public、scripts、配置文件与 package-lock.json。删除项目文件夹不会自动清理浏览器中的个人纪录。
